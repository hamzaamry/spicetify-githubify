# GitHubify

A GitHub-style theme for [Spicetify](https://spicetify.app), with four color schemes: `dark`, `dimmed`, `light` and `high-contrast`.

> Inspired by GitHub's Primer design. Not affiliated with or endorsed by GitHub.

## Install

```sh
git clone https://github.com/hamzaamry/spicetify-githubify ~/.config/spicetify/Themes/githubify
spicetify config current_theme githubify color_scheme dark
spicetify apply
```

Swap `dark` for `dimmed`, `light` or `high-contrast` to change the scheme.

## Tested on

Spotify 1.3.4 (Linux), Spicetify 2.46.4.
